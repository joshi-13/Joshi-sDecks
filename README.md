# Joshi's Decks
## A mod that adds 8 Decks (more to come soon)


### 4 Decks that change what appears in shop 
- Joker Deck (Only Jokers will appear in shop.)

- Tarot Deck (Only Tarot cards will appear in shop.)

- Spectral Deck (Only Spectral will appear in shop.)

- Card Deck (Only Playing cards will appear in shop. Start with the Magic Trick and Illusion Vouchers.)

### 4 Decks that change what rarity of Jokers will appear during the run
- Common Deck (Only Common Jokers will appear.)

- Uncommon Deck (Only Uncommon Jokers will appear.)

- Rare Deck (Only Rare Jokers will appear.)

- Legendary Deck (Only Legendary Jokers will appear. Permanent Showman effect.)
